## 4. Temuan Baru — Detail dan Bukti

### H-1 — Penimpaan `~/.claude/CLAUDE.md` (data loss, klaim README palsu)

- **Lokasi**: `setup.sh :: create_claude_code_config` (baseline: `cat > "$CLAUDE_DIR/CLAUDE.md"`).
- **Dampak**: instruksi pribadi user di CLAUDE.md dihapus diam-diam setiap
  kali setup dijalankan ulang. README baris "Marker-guarded files ...
  preserve your personal instructions across re-runs" tidak berlaku untuk
  file ini — satu-satunya file instruksi agent yang TIDAK marker-guarded
  (AGENTS.md, GEMINI.md, windsurf rules semuanya aman via `merge_agents_md`).
- **Bukti reproduksi (sebelum fix)**: ditulis `# CATATAN PRIBADI SAYA` ke
  CLAUDE.md -> re-run setup -> file berisi murni output generator, string
  pribadi **hilang** (`rg -c "CATATAN PRIBADI"` -> no match).
- **Fix**: CLAUDE.md kini dimerge lewat `merge_agents_md` (marker
  `<!-- agent-enhancements:begin/end -->`).
- **Bukti pasca-fix**: catatan pribadi tetap di baris 1, blok terjaga,
  re-run kedua tidak menduplikasi blok (`rg -c begin` = 1).

### H-2 — Index nondeterministik (diff ~50k baris per regenerasi)

- **Lokasi**: index builder heredoc di `setup.sh :: aggregate_skills` —
  `skills = list(skills_by_name.values())` mengikuti urutan insertion yang
  berasal dari urutan `find` (readdir, berbeda antar mesin/run).
- **Dampak**: regenerasi di mesin mana pun menghasilkan diff ~52.886 baris
  di `all-skills.json` dan ~45.124 baris di `agent-registry.json` walau
  **konten 100% identik** (diverifikasi: 3.094 nama sama, 0 perbedaan field).
  Merusak reviewability dan jejak audit (CONTRACT R208), dan membuat "git
  blame" indeks tidak berguna.
- **Bukti**: perbandingan semantik committed vs regen — `names sama persis:
  True`, `perbedaan field: TIDAK ADA`, hanya urutan + timestamp.
- **Fix**: `skills.sort(key=lambda s: s['name'])` (plus turunannya:
  `categories`, `agent_skill_counts`, `sources_seen` kini deterministik).
- **Bukti pasca-fix**: dua run berturut-turut menghasilkan file identik
  byte-per-byte kecuali `last_updated`; index dan registry ter-sort (dikunci
  `test_committed_index_is_sorted`, `test_registry_entries_are_sorted`).

### M-1 — Drift artefak committed (3 jenis)

1. **Prompts cursor/kiro/windsurf**: versi committed adalah teks hand-written
   lama bawa angka "2,884+" (cursor: 20 baris), sementara `setup_prompts`
   menimpanya dengan prompt asli dari koleksi vendored (cursor: 206 baris)
   setiap kali agent terdeteksi. Artefak kini di-commit sesuai output
   pipeline (perilaku terdokumentasi "refreshed at setup time").
2. **Memory hooks** copilot/cursor/kiro/windsurf: committed tanpa trailing
   newline (only diff) — diregenerasi agar identik byte-per-byte dengan
   generator; `test_sync` mengunci keduanya.
3. **`config/detected-agents.sh`**: berisi `AGENTS=(claude-code codex opencode
   gemini-cli)` — state mesin milik maintainer sebelumnya. File ini murni
   state lokal (agent apa yang kebetulan terpasang), selalu berubah antar
   mesin, dan kini di-gitignore + untracked. `launch-agent.sh` sudah
   toleran terhadap ketiadaannya (`source ... || true` + default `AGENTS=()`).

### M-2 — Merge config fatal terhadap setup

- **Lokasi**: `merge_json_config` / `merge_yaml_config`.
- **Dampak**: `~/.claude/settings.json` user yang rusak (JSON invalid)
  membuat `python3 -c` melempar traceback -> exit 1 -> `set -e` menggugurkan
  SELURUH setup di tengah jalan (agent berikutnya tidak dikonfigurasi).
  PyYAML yang tidak terpasang memberi efek sama untuk jalur YAML.
- **Bukti pasca-fix**: settings.json sengaja dirusak `{ JSON RUSAK !!!` ->
  log `[ERROR] Merge failed ... original restored, skipping this agent` ->
  setup tetap **"Setup Complete!"** exit 0, file user dikembalikan utuh
  dari backup, agent lain tetap terkonfigurasi.

### M-3 / M-4 — Klaim angka dokumentasi

- README §MCP: "36 candidate MCP servers" -> aktual **38** (P0=5, P1=22,
  P2=11). Fixed + dikunci `test_readme_mcp_count_matches_roadmap`.
- Universal prompt & skills README: "2,884+" (angka total era lama),
  atribusi "primary source" salah kaprah, daftar sources di prompt tidak
  lengkap (tanpa replica-skill & anthropic-skills). Diperbaiki di HEREDOC
  generator (bukan hanya artefak) agar tidak muncul kembali, lalu disinkron
  (`test_sync` menjamin).

### M-5 — 6 test selalu skip di CI

`test_link_skills` (6 assertions: default set, idempotency, named
link/unlink, unlink-all, user-owned protection) memerlukan tree
`by-category/` yang hanya dibuat setup.sh — tidak pernah dijalankan CI,
sehingga fitur native linking (fitur andalan README) **tidak teruji di CI
sama sekali**. Job `integration-tests` kini menjalankan `setup.sh` lebih
dahulu (aman: runner tidak punya agent CLI, tidak ada tulisan di luar
checkout + HOME runner).

### L-1 — Nama skill `.` / `..` lolos sanitasi

Sanitasi hanya mengganti `/` dengan `-`. Nama `..` menghasilkan
`by-category/general/..` (root by-category). PoC: `rm -rf` modern menolak
menghapus path berujung `/.` / `/..` (safeguard coreutils) sehingga vektornya
bukan destruksi data, melainkan copy yang mendarat di level direktori yang
salah + indeks kacau. Tetap di-guard (skip + warn) sebagai defense-in-depth
terhadap SKILL.md malicious dari sumber pihak ketiga.

### L-2 / L-3 / L-4 — Kebersihan minor

`datetime.utcnow()` -> `datetime.now(timezone.utc)` (deprecation Python
3.12+); header "FIXED VERSION" dihapus (R001); docstring test jadi raw
string (menghilangkan `SyntaxWarning` di `py_compile`).

## 7. Observasi & Rekomendasi (tanpa perubahan kode)

1. **Ukuran repository** — working tree 825 MB + `.git` 295 MB; berat
   terbesar: `agentic-awesome-skills/data/aas-v1/skill-content.v1.ndjson`
   (26 MB), PDF slide claude-mem (~100 MB), GIF headroom (20 MB), video
   onboarding (6,7 MB), PNG ECC (5,5 MB). Clone bisa >10 menit di koneksi
   lambat. **Rekomendasi**: Git LFS untuk aset biner vendored, atau
   menyediakan "slim release" (tarball tanpa `plans/`, `data/`, aset media)
   untuk konsumen yang hanya butuh skill.
2. **`doc-coauthoring` tanpa LICENSE.txt** — diverifikasi ke upstream
   `anthropics/skills`: direktori tersebut memang hanya berisi SKILL.md di
   upstream juga. Gap lisensi ada di upstream, salinan vendoring setia.
   Rekomendasi: catat di `docs/LICENSE_AUDIT.md` (README sudah menyebut
   "per-skill LICENSE.txt" — kini 18/19).
3. **105 sub-skill nested** di dalam meta-skill `game-development`
   (agentic-awesome-skills) tidak diindeks individual — by design
   (meta-skill), namun tidak terdokumentasi. Rekomendasi: satu paragraf di
   `docs/SKILLS.md`.
4. **Backup config menumpuk** — `merge_*_config` meninggalkan
   `<file>.backup.<epoch>` tanpa rotasi di HOME user. Rekomendasi: rotasi
   (simpan N terakhir) untuk rilis berikutnya.
5. **Compliance commit (R201/R205/R206)** — 41 commit: 36 membawa trailer
   `Agent:`, 35 subjek konvensional; selisihnya merge commits dan commit
   awal repo (check CI bersifat advisory — sesuai desain). Ke depan
   maintainers sebaiknya tetap menyertakan metadata agent pada commit
   non-merge.
6. **Skipped-test sebelumnya** — kini CI membangun registry, namun bijak
   menambahkan badge/gate yang memfail build jika ada test skip tak terduga.

# Contributing

This repository is governed by [CONTRACT.md](../CONTRACT.md) - read it
first. This page summarizes the practical workflow.

## What lives where

| Path | Ownership |
|------|-----------|
| `unified-integration/`, `docs/`, `.github/`, `README.md`, `CONTRACT.md` | owned by this project |
| `agentic-awesome-skills/`, `claude-mem/`, `ECC/`, `headroom/`, `ponytail/`, `superpowers/`, `system-prompts-and-models-of-ai-tools/` | vendored copies - contribute upstream |

## Standard flow (CONTRACT §5.1)

```bash
# 1. read the contract and architecture docs
$EDITOR CONTRACT.md docs/ARCHITECTURE.md

# 2. create a branch
git checkout -b fix/short-description

# 3. make focused changes (edit canonical files; no *-fixed/*-new/*-v2 files)

# 4. run the required test suites
python3 unified-integration/tests/run-tests.py
cd ECC && node tests/run-all.js   # must pass (CONTRACT §6.1)

# 5. update docs/ when interfaces or configuration change

# 6. commit with conventional format + agent traceability (R201, R205-R207)
git commit -m "fix(memory): one-line description" \
           -m "Agent: <agent-name> | Session: <session-id> | Task: <task>"

# 7. push and open a PR
```

## Commit metadata (mandatory for agent-made changes)

```text
fix(memory): replace SQL string interpolation in bash hooks

Agent: Claude Code | Session: abc123 | Task: security audit fix
Context: CONTRACT R101 violation

Co-Authored-By: Claude Code <abc123>
```

CI validates conventional subjects and warns when the `Agent:` trailer is
missing (human commits are exempt).

## Things that need human approval first (CONTRACT §4.2)

- changing the skills aggregation architecture or the index schema
- adding/removing supported agents (the `AGENTS` list)
- altering the memory database schema or the compression engine interface
- renaming/moving canonical files

## Keep generators and artifacts in sync

Several files under `unified-integration/` are generated by heredoc
templates inside `setup.sh`. When you edit one side, update the other -
`tests/test_sync.py` fails the build on drift.

## Hygiene

- No temp/backup files (`*.tmp.*`, `*.bak`, `*-fixed.*`) - CI blocks them.
- Machine-local state (`config/detected-agents.sh`, `.claude/settings.local.json`)
  is never committed; `.gitignore` enforces it.

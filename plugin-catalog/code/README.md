# Code Skills

Skill untuk authoring, refactoring, optimasi kode, dan app-cloning clean-room. Total **4 plugin sources**.

| Plugin | Source | Fokus utama |
|--------|--------|-------------|
| Matt Pocock Skills | github.com/mattpocock/ | TypeScript types, generics, Zod |
| Karpathy Skills | github.com/multica-ai/andrej-karpathy-skills | Minimal code, first-principles, ML |
| Agent Skills (Addy Osmani) | github.com/addyosmani/ | Web perf, a11y, modern frontend |
| Replica Skill | github.com/Jakeschincariol/replica-skill | 11 sub-skill clone app clean-room (vendored) |

Filosofi: kode harus (1) **bisa dibaca lebih dulu**, (2) **seminimal mungkin tanpa kehilangan intent**, (3) **punya test sebelum ditambah abstraksi**. Atribut ini diwariskan ke `.cursorrules` global.

Lihat juga folder manifest JSON di kategori ini.

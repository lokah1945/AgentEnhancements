## Updating and verification

Regenerate the skills index through `unified-integration/setup.sh` after
changing vendored sources; never edit it manually. Rebuild the capability
registry and L0 map, then run the count generator with `--write`. A second
write preserves bytes and timestamps when counts are unchanged.

The checker verifies generated blocks and common count claims in current
root guides. Historical audit reports, benchmark evidence, ADRs and the
changelog retain their original revision-specific numbers. It does not
claim to understand every numerical assertion in prose or replace test
execution, credential checks, installed-host checks or licensing review.

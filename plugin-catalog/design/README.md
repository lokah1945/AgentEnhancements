Skill untuk UI/UX, presentasi, dan diagram. Total **4 plugin sources**.

| Plugin | Source | Fokus utama |
|--------|--------|-------------|
| UI UX Pro Max | github.com/nextlevelbuilder/ | Design tokens, a11y palette, component spec |
| Impeccable | github.com/pbakaus/ | Visual polish audit (alignment, contrast, motion) |
| PPT Master | github.com/hugohe3/ppt-master | Storytelling + slide layout |

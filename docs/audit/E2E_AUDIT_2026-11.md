## Findings

### HIGH — Fixed

#### H-1: Setup Script Overwrites User Files
**Location**: `unified-integration/setup.sh` lines 45–52
**Issue**: `cp "$skill_path" "$target_dir/SKILL.md"` overwrites user-modified skill files without backup/merge.
**Impact**: User customizations lost on re-run.
**Fix Applied**: Changed to merge semantics — only write if target doesn't exist or content differs. Added `--force` flag for explicit overwrite.
**Verification**: `test_setup_idempotent.py` passes.

#### H-2: Registry Output Non-Deterministic
**Location**: `unified-integration/scripts/registry.py` line 89
**Issue**: `find` output order filesystem-dependent → `catalog.json` spurious diffs on rebuild.
**Impact**: Noise in PR diffs, false positives in CI.
**Fix Applied**: Added `sort` to discovery pipeline. `catalog.json` keys now sorted.
**Verification**: `test_registry_deterministic.py` — 100 runs, identical output.

#### H-3: MCP Server Secrets in Error Messages
**Location**: `skills/multimedia-writing/anthropic-skills/skills/mcp-builder/SKILL.md` Example 1
**Issue**: Example code echoes `GITHUB_TOKEN` in error path: `raise ValueError(f"GITHUB_TOKEN not set: {token}")`
**Impact**: Secret leakage in logs/traces.
**Fix Applied**: Removed token from error message. Generic "not set" only.
**Verification**: `test_mcp_secret_leak.py` — no secrets in stdout/stderr.

### MEDIUM — In Progress

#### M-1: Skill Discovery Misses Nested Skills
**Location**: `registry.py` line 67
**Issue**: `rglob("SKILL.md")` finds all, but category extraction assumes `skills/<cat>/<slug>/SKILL.md`. Fails for `skills/<cat>/<subcat>/<slug>/SKILL.md`.
**Status**: Refactoring to parse relative path dynamically.

#### M-2: Cursor Rule Conversion Loses Frontmatter
**Location**: `setup.sh` lines 58–70
**Issue**: `.mdc` generation wraps entire SKILL.md but Cursor expects frontmatter at top of `.mdc`. Current output has skill frontmatter *inside* rule frontmatter.
**Status**: Rewriting converter to extract skill frontmatter → merge into rule frontmatter.

#### M-3: Registry Keyword Matching Too Naive
**Location**: `registry.py` line 105
**Issue**: Simple substring match on `trigger_keywords` → false positives (e.g., "mcp" matches "mcpc", "mcp-builder" matches "mcp").
**Status**: Implementing word-boundary regex + TF-IDF scoring.

#### M-4: Test Suite Missing MCP Integration Tests
**Location**: `unified-integration/tests/`
**Issue**: 236 tests but 0 test actual MCP server communication (stdio transport, tool calls).
**Status**: Adding `test_mcp_integration.py` with `mcp` dev server fixtures.

### LOW — Documented

#### L-1: Karpathy Skill Examples Use `print()`
**Location**: `skills/code/karpathy-skills/SKILL.md` Examples
**Issue**: Examples use `print()` for output. Better: return values for testability.
**Resolution**: Documented; examples updated in next skill revision.

#### L-2: Anthropic Skills Category Overloaded
**Location**: `plugin-catalog/catalog.json` category `multimedia-writing`
**Issue**: 6 skills in one category. Sub-categories (doc-processing, mcp, skill-authoring, multimedia) would improve discovery.
**Resolution**: Planned for v0.2.0 catalog restructure.

#### L-3: No Skill Deprecation Path
**Location**: `CONTRACT.md` §3.1
**Issue**: `status: deprecated` defined but no tooling to hide/warn.
**Resolution**: Add deprecation warning in `registry.py map` output.

#### L-4: Setup Script Not Windows-Compatible
**Location**: `unified-integration/setup.sh`
**Issue**: Bash-only. Windows users (Claude Code on Windows) need `.ps1` or Python equivalent.
**Resolution**: `setup.py` in progress.

#### L-5: MCP Server Health Tool Schema Undefined
**Location**: `plugin-catalog/mcp-servers.json`
**Issue**: `health` tool listed but no standard output schema defined.
**Resolution**: Define `HealthResponse` schema in `mcp-builder` skill.

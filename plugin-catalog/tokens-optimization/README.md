# Tokens & Optimization Skills

Skill untuk kompresi, throughput, dan eksekusi agresif. Total **4 plugin sources**.

| Plugin | Source | Fokus utama |
|--------|--------|-------------|
| GStack | github.com/garrytan/gstack | Prompt compression + response cache |
| Caveman | github.com/JuliusBrussee/Caveman | Extreme shorthand compression |
| GSD (Get Shit Done) | github.com/gsd-build/get-shit-done | Atomic checklist + parallel dispatch |
| BMAD Method | github.com/bmad-code-org/ | Persona-driven agile orchestration |

Filosofi: token adalah resource mahal. Skill di kategori ini boleh dipanggil layer atas (GSD/BMAD) untuk mengorkestrasi sub-agent dengan budget ketat.

Gunakan bersama `unified-integration/compression/` (headroom) yang sudah ada di repo.

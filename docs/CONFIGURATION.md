## 1. Environment Variables

### 1.1 Core Variables (User-Configurable)

| Variable | Description | Default | Required |
|----------|-------------|---------|----------|
| `AGENT_ENHANCEMENTS_BASE_DIR` | Root directory of the project | `/root/agent-enhancements` | No |
| `AGENT_MEMORY_ROOT` | Memory database location | `~/.agent-memory` | No |
| `HEADROOM_BIN` | Path to headroom binary | Auto-detect | No |
| `AGENT_SKILLS_DIR` | Skills registry location | `$BASE_DIR/unified-integration/skills` | No |
| `AGENT_COMPRESSION_CONFIG` | Compression config path | `$UNIFIED_DIR/compression/config.yaml` | No |
| `AGENT_PROMPTS_DIR` | Prompts directory | `$UNIFIED_DIR/prompts` | No |

### 1.2 Agent-Set Variables (Auto-Configured)

These are set by `launch-agent.sh` and should NOT be set manually:

| Variable | Set By | Purpose |
|----------|--------|---------|
| `AGENT_MEMORY_ROOT` | launch-agent.sh | Memory location for hooks |
| `AGENT_SKILLS_DIR` | launch-agent.sh | Skills registry for load-skills.py |
| `AGENT_COMPRESSION_CONFIG` | launch-agent.sh | Compression config for compress.py |
| `AGENT_PROMPTS_DIR` | launch-agent.sh | Prompts directory |
| `AGENT_ENHANCEMENTS_BASE_DIR` | launch-agent.sh | Project root for relative paths |
| `AGENT_ENHANCEMENTS_UNIFIED_DIR` | launch-agent.sh | Unified integration directory |

## 2. File-Based Configuration

### 2.1 Detected Agents (`unified-integration/config/detected-agents.sh`)

Auto-generated by `setup.sh`. Do not edit manually.

```bash
AGENTS=(claude-code codex opencode cursor gemini-cli windsurf copilot kiro)
```

### 2.2 Memory Config (`unified-integration/memory/config.yaml`)

```yaml
memory:
  backend: "sqlite"           # sqlite, file, redis
  path: "~/.agent-memory"     # Expands tilde
  
  types:
    - name: "project_context"
      description: "Project-specific context"
      ttl_days: 365
      scope: "project"
    - name: "user_preferences"
      description: "User coding style"
      ttl_days: 730
      scope: "global"
    # ... (see ARCHITECTURE.md for full list)

  agents:
    claude-code:
      plugin_path: "/root/agent-enhancements/claude-mem/.claude-plugin"
      enabled: true
    # ... per-agent plugin paths

  auto_save:
    - event: "task_complete"
    - event: "decision_made"
    - event: "pattern_discovered"
    - event: "session_end"
    - interval_minutes: 30

  retrieval:
    max_results: 10
    relevance_threshold: 0.7
    include_metadata: true
```

### 2.3 Compression Config (`unified-integration/compression/config.yaml`)

```yaml
compression:
  engine: "headroom"          # headroom, native, none
  
  headroom:
    binary_path: "headroom"   # Or full path
    
    modes:
      code: "smart"
      logs: "aggressive"
      json: "schema"
      markdown: "semantic"
      generic: "balanced"
    
    budgets:
      default: 8000
      coding_task: 12000
      code_review: 15000
      debugging: 10000
    
    trigger_at_percent: 0.75
    target_percent: 0.5

  native:
    enabled: true
    algorithms:
      - "deduplicate"
      - "summarize_logs"
      - "compress_json"
      - "trim_whitespace"
      - "extract_key_code"

  agents:
    claude-code:
      enabled: true
      budget: 200000
    # ... per-agent budgets
```

## 4. Skill Frontmatter Schema

Every `SKILL.md` must have this frontmatter:

```yaml
---
name: "skill-name"                    # Required: unique identifier
description: "What this skill does"   # Required: one-line summary
risk: "safe|medium|critical"          # Required: safe, medium, critical
source: "source-name"                 # Required: origin (agentic-awesome-skills, ECC, etc.)
date_added: "2026-11-01"              # Required: ISO date
author: "author-name"                 # Optional
category: "security|architecture|testing|refactoring|code-review|documentation|devops|ai-ml|productivity|general"
tags:                                 # Optional: list of tags
  - "tag1"
  - "tag2"
tools:                                # Required: compatible agents
  - "claude-code"
  - "codex"
  - "cursor"
  - "gemini-cli"
  - "opencode"
  - "copilot"
  - "windsurf"
  - "kiro"
---
```

## 5. Customization Examples

### 5.1 Custom Project Location
```bash
export AGENT_ENHANCEMENTS_BASE_DIR="/opt/my-agent-enhancements"
/opt/my-agent-enhancements/unified-integration/setup.sh
```

### 5.2 Custom Memory Location
```bash
export AGENT_MEMORY_ROOT="/data/agent-memory"
# Then run setup.sh or launch-agent.sh
```

### 5.3 Custom Headroom Binary
```bash
export HEADROOM_BIN="/usr/local/bin/headroom"
# Or build from source and point to it
```

### 5.4 Disable Compression for Specific Agent
Edit `unified-integration/compression/config.yaml`:
```yaml
agents:
  copilot:
    enabled: false
    budget: 32000
```

### 5.5 Add Custom Memory Type
Edit `unified-integration/memory/config.yaml`:
```yaml
types:
  - name: "deployment_notes"
    description: "Deployment history and configs"
    ttl_days: 365
    scope: "project"
```
Then re-run `setup.sh` to regenerate hooks.

## 6. Validation

### 6.1 Validate All Configs
```bash
# Check bash syntax
bash -n unified-integration/setup.sh
bash -n unified-integration/update-skills.sh
bash -n unified-integration/launch-agent.sh

# Check Python syntax
python3 -m py_compile unified-integration/scripts/*.py
python3 -m py_compile unified-integration/memory/hooks/*.py

# Check YAML syntax
python3 -c "import yaml; yaml.safe_load(open('unified-integration/memory/config.yaml'))"
python3 -c "import yaml; yaml.safe_load(open('unified-integration/compression/config.yaml'))"

# Check JSON syntax
python3 -c "import json; json.load(open('unified-integration/skills/all-skills.json'))"
```

### 6.2 Test Agent Configs
```bash
# Test memory init
unified-integration/memory/init-memory.sh

# Test skill loading
python3 unified-integration/scripts/load-skills.py claude-code "security audit"

# Test memory
python3 unified-integration/scripts/memory.py claude-code save test_key "test value"
python3 unified-integration/scripts/memory.py claude-code load test_key

# Test compression
echo "large content..." | unified-integration/compression/compress.sh auto claude-code
```

## 7. Troubleshooting Config Issues

| Issue | Check | Fix |
|-------|-------|-----|
| Agent not detected | `command -v <agent>` | Install agent or add to PATH |
| Skills not loading | `all-skills.json` exists? | Re-run `setup.sh` |
| Memory not persisting | `~/.agent-memory/memory.db` exists? | Run `init-memory.sh` |
| Compression failing | `headroom` in PATH? | Build headroom or set `HEADROOM_BIN` |
| Hooks not firing | `settings.json` valid JSON? | Re-run `setup.sh` |
| Config not applied | Agent config dir correct? | Check `~/.claude/`, `~/.codex/`, etc. |
